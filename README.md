# Фінанси 2027

Вебзастосунок для фінансового управління **Амбулаторією**, **Скринінгом**, **Психотерапією** та окремим простором **особистих фінансів**.

**Стан:** початок розробки. Усі тестові суми демонстраційні. Немає підключень до банків, ДПС чи реальних рахунків.

## Головне джерело вимог
[Єдина фінансова система 2027 — актуальна специфікація](https://docs.google.com/document/d/1NZHujPiALISLj8S3_pD02Mf2mqiHipH4_IpleZ0dqnk/edit).

## Дизайн
Погоджений baseline — **Figma Make v0.2 (React, TypeScript, Vite, Tailwind)**. Зберігаємо його вигляд; нові екрани реалізуємо в тому самому стилі.

## Правила
- Публічний GitHub містить лише код, штучні демодані й тести. **Не додавати** банківські виписки, токени, секрети, реальні фінансові операції чи персональні медичні дані.
- BUDGET, ACTUAL і FORECAST — різні представлення; нарахування, зобов'язання та банківський платіж — різні сутності.
- Платіж у статусі planned/submitted не зменшує борг до звірки з банківським фактом.
- Один POS-пакет ПриватБанку може містити скринінги та платні прийоми Амбулаторії.
- Саска входить у виробіток лікарів, але не є найманою працівницею для Д1/4ДФ.
- Особисті фінанси відділені від бізнесу; власні перекази не створюють подвійного доходу.
- Не повертати старі скасовані бізнес-правила з попередніх версій специфікації.
