# План розробки «Фінанси 2027»

Джерело архітектурних рішень: [Єдина фінансова система 2027](https://docs.google.com/document/d/1NZHujPiALISLj8S3_pD02Mf2mqiHipH4_IpleZ0dqnk/edit).

## Черговість
1. F00 — GitHub, перенесення Figma v0.2, CI.
2. F01 — дизайн-система й розділення App.tsx без зміни UI.
3. F02 — фінансова доменна модель та тести.
4. F03 — річний бюджет і наступний місяць (масове редагування).
5. F04 — зобов'язання, часткові платежі, звірка.
6. F05 — банк, POS, FX, внутрішні перекази.
7. F06 — доходи трьох бізнес-напрямків.
8. F07 — табель, зарплата, Саска як власниця, три відомості.
9. F08 — податкові звіти і зарахування ДПС.
10. F09 — особисті фінанси, цілі та перекази ФОП→особисте.
11. F10 — бюджет/факт/прогноз, cash-flow, контроль та фінальна звірка.

## Definition of Done
- Кожне правило звірене з чинною специфікацією.
- Не внесено жодних реальних платежів, медичних даних чи секретів.
- Збережено затверджений Figma дизайн.
- Тести, перевірка типів та production build успішні.
- Існують стани помилки, невизначеності, неповної оплати й невідповідності.
- Пройдено перевірку без подвійного врахування грошей.

**Поточний стан:** початковий доменний модуль і тести завантажуються окремо від UI. До перенесення React/Figma файлів репозиторій НЕ можна вважати готовим для збірки вебінтерфейсу.
