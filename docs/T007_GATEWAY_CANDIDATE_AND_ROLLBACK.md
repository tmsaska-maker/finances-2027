# T007 — приватний фінансовий gateway: кандидат, без деплою

## Підтверджений стан 16.11.2026

На чинному Lightsail порт 8092 належить Docker Compose сервісу `finances2027/gateway`. Він відповідає 403 на анонімний `GET /finance-api/session`. Проєктний код `server/browser-gateway.mjs` на той самий анонімний GET повертає 200 та `authenticated:false`. Наявний живий контейнер використовує іншу команду запуску (`node_other_command`), зібраний з Compose-конфігурації фінансового каталогу, без app bind-mount. Точний образ, його вміст, причина 403 не доведені.

## Пакет кандидата

`server/Dockerfile.gateway` ізолює лише нові файли шлюзу, не додає ключі API або паролі. Ручний workflow `manual-private-finance-gateway-build.yml` лише тестує код, збирає Docker-образ **на GitHub-hosted runner** і публікує короткоживучий артефакт для інспекції. Немає AWS OIDC, SSH, відкритих портів чи завантаження образу на Lightsail.

**Не запускати цей образ на робочому сервері довільною командою.** Поточний `browser-gateway-main.mjs` приймає API виключно на `127.0.0.1:8091`, а тому окремий Docker-контейнер на bridge network не побачить API на loopback хоста. Host networking із існуючим портом 8092 конфліктує з живим gateway; заборонено замінювати його без окремого узгодженого deployment/rollback-процесу.

## Перед ручним перемиканням (поки НЕ зроблено)

1. Без розкриття секретів і персональних даних перевірити фактичну конфігурацію запуску, exact образ і можливість відтворення/відкату існуючого `finances2027/gateway`.
2. Погодити окрему приватну HTTPS-адресу, не відкривати реальні фінанси на публічному демо-сайті.
3. Виправити архітектуру зв'язку gateway → finance API без експонування API; кандидат має тестуватися на окремому loopback порту з фінансовими **синтетичними** даними.
4. Перевірити HTTPS/Origin, HttpOnly/Secure cookie, логін/логаут, rate-limit, CSRF, відмову доступу без сесії, відкат та відсутність впливу на Скринінг 40+.
5. Тільки після окремого схвалення виконувати finance-only деплой, без зміни Caddy маршрутів Скринінгу і без `docker compose down`.

Цей документ і workflow — **підготовка кандидата**, не свідчення готовності до production.
