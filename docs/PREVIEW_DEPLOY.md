# Публікація погодженого дизайну Figma · GitHub Pages

Статус: налаштовано pipeline; сайт **ще не опублікований** до імпорту файлів Figma та активації Pages.

## Одноразові дії
1. У GitHub відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Завантажте перевірений архів `figma-bootstrap.zip` у корінь гілки `main` через **Add file → Upload files**. Архів містить **лише** затверджені `src/App.tsx` і `src/index.css`; жодних секретів або реальних фінансових виписок.
3. GitHub Actions автоматично розпакує їх у робочому просторі збірки, збере Vite UI й опублікує GitHub Pages.
4. Перевіряйте статус у **Actions → Publish Figma Preview**.
5. Після успішного запуску URL: https://tmsaska-maker.github.io/finances-2027/

**Обережно:** це публічний UI для перегляду демоданих. Бекенд, реальні платежі, автентифікація та безпечне фінансове сховище тут не розгортаються.

## Надалі
Поточне розпакування з ZIP — лише тимчасовий bootstrap через обмеження інструменту перенесення великих файлів. Для повноцінної спільної розробки F00 необхідно перенести `src/App.tsx` і `src/index.css` як звичайні файли в GitHub; тоді сам ZIP можна буде прибрати. Кожний merge у `main`, що змінює джерела UI, перевипускатиме сайт.
