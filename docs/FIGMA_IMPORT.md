# Перенесення погодженого Figma Make коду

**Головний принцип:** не заміняти дизайн незалежним шаблоном. Затверджено Figma Make v0.2.

Підготовлений локальний архів: `Фінанси_2027_GitHub_Starter_v0.3.zip` (прототип React/Vite/Tailwind + фінансовий модуль + тести).

**Ще потрібно перенести із цього архіву**:
- `src/App.tsx` — оригінальний UI і доданий екран витрат;
- `src/index.css` — всі погоджені стилі;
- `src/main.tsx`, `src/vite-env.d.ts`;
- `index.html`, `vite.config.ts`, `tsconfig.json`;
- папку `.figma/make/`, якщо потрібна сумісність із Figma Make.

Не публікувати `node_modules`, `dist`, `.env`, справжні платіжні дані.
Не змінювати UI до першої перевірки збірки. Після перенесення запустити `npm install`, `npm test`, `npm run typecheck`, `npm run build`.

**Важливо:** CI може бути червоним, доки перелічені UI файли не перенесені; це відомий етап міграції, а не підтверджений дефект Figma дизайну.
