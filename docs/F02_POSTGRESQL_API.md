# F02 — ізольована PostgreSQL + приватний API (підготовлено, НЕ розгорнуто)

## Призначення
Новий фінансовий backend у `server/` відокремлений від Screening40.
Дані зберігаються окремими таблицями з обов'язковими ID, валютами,
позитивними сумами в мінорних одиницях та індексами.
Підтверджений платіж повинен мати пов'язану витрату в банку відповідного проєкту і валюти.
Сума розподілених підтверджених платежів не може перевищувати банківську витрату.

## Безпечна послідовність розгортання
1. Створити окрему БД і окремого користувача **тільки для фінансів**.
   Не змінювати Screening40 Docker, його базу чи конфігурацію Caddy.
2. Поставити Node 22 та інсталювати залежності командою `npm install` у `server/`.
3. Спочатку у новій порожній БД виконати `server/sql/001_initial.sql` під окремим користувачем.
4. Зберегти секрети лише в закритому server-side env, не в repo чи клієнтському коді.
5. Запускати `NODE_ENV=production node server/main.mjs`: тільки loopback `127.0.0.1:8091`.
6. Налаштувати захищену серверну авторизацію, міграції, резервні копії та тестове відновлення перед будь-яким вводом реальних даних.

**Зараз НЕ виконувати кроки на Lightsail без окремої перевірки**
ресурсів, доступів, резервних копій і плану відкату.
API не опублікований Caddy і не під'єднаний до React UI.
Публічний сайт містить лише демонстраційні дані.

## Наступне
Додати інтеграційні тести проти тимчасової PostgreSQL в CI,
окреме міграційне керування, аудит змін, серверну авторизацію
й read-only перевірку балансу; потім окреме розгортання.
